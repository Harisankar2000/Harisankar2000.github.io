Projects

Featured · personal project

NeoBank

A simulated digital bank built on a double-entry ledger: accounts, deposits, beneficiaries, transfers and statements.

  • Transfers are atomic, concurrency-safe and idempotent, using ordered row locks, deadlock retries and stored Idempotency-Keys. Integration tests run 50 parallel transfers and no account is overdrawn.
  • Daily limits and rule-based fraud checks hold suspicious transfers in a suspense account for admin approval. Reversals never edit history.
  • Events go to Kafka through a transactional outbox, with an idempotent consumer for notifications.
  • React customer app and admin console, with 41 Vitest tests run against real PostgreSQL and Redis.
